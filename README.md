# Roadbook

Ton road trip en van, fourgon aménagé ou camping-car, jour par jour, même sans réseau.

- Application : `index.html` (HTML, CSS et JavaScript, sans serveur à faire tourner).
- Validation des avis de la communauté : `moderation.html`.
- Détails techniques, sources et licences : `LISEZ-MOI.md`.
